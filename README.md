# Web Development — Class Lectures & Practicals

A continuously updated repository containing lecture-wise code, practical exercises, examples, and classwork from my Web Development course.

## About This Repository

This repository serves as my personal Web Development learning archive.

I update it regularly with the code and exercises covered during class, keeping the work organised by lecture so I can revisit concepts, review examples, and track my progress throughout the course.

## What You'll Find Here

- Lecture-wise source code
- Classroom demonstrations and examples
- Practical exercises
- Programming experiments
- Code written while learning and practising Web Development

## Learning Approach

The repository is updated as the course progresses. Rather than keeping only final assignments, it preserves the smaller examples and experiments completed during lectures.

This makes it useful as a reference for revision, debugging, and understanding how concepts develop through practice.

## Updates

New lecture folders, exercises, and code examples are added as they are covered in class.

## Purpose

To maintain an organised record of my Web Development coursework and document my progress through hands-on programming.
